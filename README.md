# 猎鼠 · 猫咪小游戏

给猫咪玩的 iPad 全屏网页游戏。单文件 `index.html`，零依赖、无需构建、打开即玩。

## 玩法

- 亮黄绿色小老鼠在深蓝背景上随机跑动：潜伏 70–180 px/s、常速 260–640 px/s、爆发冲刺 780–1200 px/s，每 0.3–1.3 秒换档；多频游走扰动 + 急停急转 + 反向折返，目标点可落在屏外，冲到屏幕边缘后镜面反弹再跑回来。
- 猫爪触碰命中后，老鼠翻倒淡出并炸开粒子，0.72 秒后从随机屏幕边缘跑进一只新老鼠。
- 跑动时播放高频「吱吱」声与窸窣声，捕获时播放下降啸叫。全部音效由 JS 预合成为 WAV（data URI），无外部音频文件。

## 设计要点

| 项 | 实现 |
| --- | --- |
| 颜色 | 深蓝黑底 `#050912` + 亮黄绿 `#F2FF38` 身体 + 蓝 `#7FD4FF` 耳朵/尾巴/鼻子。猫是二色视觉，对黄绿、蓝最敏感，红色接近灰暗，故不使用红色 |
| 造型 | 一体化贝塞尔纺锤轮廓（尾根 → 肩 → 尖吻）+ 渐变毛色与背部高光、半露圆耳（外黄内蓝）、锥形波动长尾、四足交替步态与爪尖、带高光眼睛与弧形胡须；纯 Canvas 绘制，无图片资源 |
| 运动 | 五档速度随机换档（慢走 / 常速 / 爆发 / 急停 / 变向）+ 平滑多频游走；冲刺时近直线，急停后大幅转向；目标点含屏外区域，触边镜面反弹并重选目标，轨迹难预测；步态播放速率跟随速度 |
| 性能 | 16 帧老鼠动画与全屏背景在加载时预渲染为离屏 canvas，运行时每帧仅 1 次背景 `drawImage` + 1 次老鼠 `drawImage`；消除每帧 6 个渐变对象、`shadowBlur` 发光与两次全屏渐变填充，大幅降低 iPad Safari 的每帧开销与 GC 压力 |
| 声音 | 44.1 kHz WAV：2.2–5.6 kHz 上扬扫频 + 8–17 kHz 谐波（猫敏感）+ 低频共振（iPad 扬声器与人耳可听）；仅跑动时按 0.4–1.3 秒随机节奏发声 |
| iOS 音频适配 | 不用 Web Audio：Safari 默认 ambient 会话，静音开关会完全静音。改用 `HTMLAudioElement`（playback 会话）+ `navigator.audioSession.type='playback'` + 静音 loop 保活；首次触摸同步解锁全部音效；全屏切换、回到前台自动重激活 |
| 命中 | `touchstart` / `touchmove` 全部触点检测，命中半径按猫爪放宽；同时兼容鼠标用于本地调试 |
| 全屏与防误触 | 首次触碰自动 `requestFullscreen`；PWA standalone meta；禁用缩放、长按菜单、双指手势、边缘滑动返回、下拉刷新；画面无任何按钮 |
| 屏幕常亮 | 尝试 Wake Lock API，页面回到前台自动重新申请（iPad 上仍建议系统设置「永不」自动锁定） |

## 在 iPad 上使用

1. Safari 打开部署后的链接。
2. **首次轻触屏幕**：解锁音频（会响一声「吱」并显示「声音已开启」）并触发全屏。浏览器强制要求用户手势。
3. 分享 → **添加到主屏幕**，从主屏图标启动可彻底隐藏地址栏、搜索框与返回按钮。
4. 设置 → 显示与亮度 → 自动锁定设为「永不」；调高系统媒体音量。
5. 修复后即使 iPad 处于静音模式也能出声。若显示「声音被拦截」，再轻触一次屏幕即可重新解锁。
6. 页面底部仅有一条自动消失的人类提示，不接收触摸，不会干扰猫。

## Vercel 部署

纯静态单文件，无需构建：

1. Vercel → Add New → Project → Import 本 GitHub 仓库。
2. Framework Preset 选 `Other`；Build Command、Output Directory 均留空（仓库根目录即站点根，`index.html` 为入口）。
3. Deploy，拿到 HTTPS 链接后用 iPad Safari 打开。

## 本地预览

双击 `index.html` 即可，或：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

浏览器音频策略要求首次点击/触摸后才能解锁声音，属正常现象。
